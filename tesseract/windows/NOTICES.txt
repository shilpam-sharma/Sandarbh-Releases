Tesseract OCR, bundled with Sandarbh
====================================

Sandarbh reads scanned PDFs by running Tesseract as a separate program.
Sandarbh does not link to Tesseract or to any library below; each is used
under its own licence, which is not affected by Sandarbh's EULA and does
not affect it.  Full licence texts are in the licenses/ folder beside this
file.  The libraries were stripped of debug symbols and are otherwise
unmodified.

Built from: tesseract v5.4.0.20240606, the UB Mannheim Windows build (https://github.com/UB-Mannheim/tesseract).  Its libraries are the MSYS2
mingw-w64 packages current when that build was made; their build recipes
and sources are at https://github.com/msys2/MINGW-packages and
https://packages.msys2.org/.  Versions, where a file records one:

  libcrypto-3-x64.dll          3.3.1.0
  libiconv-2.dll               1.17.0.0
  liblz4.dll                   1.9.4.0
  liblzma-5.dll                5.6.2.0
  libwinpthread-1.dll          1.0.0.0
